##  Digital Mental Health Support System :
  A web application that helps students check their stress level and get mental health support.

##  Project Description:

This system allows students to:
    • Login to the system
    • Answer stress related questions
    • Analyze stress level
    • View stress results
    • Get tips to reduce stress
    • See stress graph
    • Give feedback

This project is developed using **Python Flask**.

##  Features
   * Student Login System
   * 10 Question Stress Assessment
   * Stress Result Analysis
   * Stress Reduction Tips
   * Mood / Stress Graph
   * Student Result History
   * Feedback Form
   * SQLite Database

##  Technologies Used
   * Python
   * Flask
   * HTML
   * CSS
   * JavaScript
   * SQLite
   * Chart.js

1. Install Python

   pip install flask
3. Run project
   python app.py
4. Open browser
   http://127.0.0.1:5000
